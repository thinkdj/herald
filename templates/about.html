About

Herald tells your app that a new version is out.

A small release server for desktop apps. You drop a build here. Every copy of the app already installed asks Herald for the latest version, hears about it, and updates itself.

  1. 1

    Publish

    Sign in, pick an app, drop the installers and their signature files. Each platform lands under one version number, from one machine or several.

  2. 2

    Announce

    Herald turns that into the feed each updater expects: Tauri's latest.json and electron-updater's latest.yml, plus a plain download link per platform.

  3. 3

    Update

    Installed apps check the feed, verify the signature, and install. Anyone else can read the same page as a changelog, or grab the installer directly.

What it is

  • One Cloudflare Worker with a database and a bucket. Nothing else to run, nothing to patch.
  • Any number of apps, each under its own short name, each with its own feeds and page.
  • Signatures travel with the build. The updater checks them; Herald never sees a private key.
  • A browser for people, a token for CI. Both publish the same way.

What it is not

  • Not a store. No accounts for users, no reviews, no analytics on who downloaded what.
  • Not an SDK. Apps keep the updater they already ship with and only change one URL.
  • Not a build system. It hosts what you give it and says nothing until you publish.
  • Not shared. One operator, one password, and the pages run no third party script.
